Privacy Policy for myPKA Tools

Effective 17 November 2026

Who uses this app

myPKA Tools is a private automation app with one user: its owner. It is not offered to the public and does not accept other users.

What data the app accesses

With the owner's consent, the app accesses the owner's own Google account data: Gmail, Calendar, Tasks, Contacts, Drive, Docs, Sheets, Slides and Forms.

How the data is used

The data is used only to run the owner's personal task, calendar, email and document workflows, at the owner's direction.

Storage and sharing

Data is processed and stored on computers the owner controls. It is not sold, not used for advertising, and not shared with third parties, other than the service providers the owner personally chooses to process their own data on their behalf. Access credentials are stored only on the owner's own computer.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke the app's access at any time at myaccount.google.com/permissions.

Contact

Questions can be raised through the GitHub account that hosts this page.
